1. ORIGIN & EARLIER CHAT ("Extract and Read Zip Files" / Argon / Hydrogen)
--------------------------------------------------------------------------------
- Goal & Owner:
  - Built for a radiologist who reads on both Mac and a Windows PC (RTX 5080)
    and wants a native, lightweight, open-source (LGPL-3.0-or-later) DICOM
    viewer modeled directly on Horos / OsiriX and its modern Swift fork IsiX
    (https://github.com/ThalesMMS/IsiX-DICOM-Viewer-macOS), running natively on
    Windows, macOS (ARM64), and Linux.
  - Not a medical device; for personal use, teaching, research, and second looks.

- Architecture & Key Decisions:
  - IsiX (~380k lines of Swift/ObjC on AppKit, Metal, CoreData) cannot compile
    on Windows; Cocotron/Metal-to-Vulkan translators were rejected.
  - Chosen approach: rebuild in Rust (`eframe`/`egui` 0.37 + `wgpu` 30 +
    `dicom-rs` 0.10), porting IsiX's math/imaging/ROI logic + unit tests file by
    file while rebuilding UI/rendering with egui + wgpu.
  - Codecs: uncompressed, JPEG baseline/lossless, JPEG 2000 (OpenJPEG C library),
    JPEG-LS (CharLS), RLE, deflate; color and multi-frame.

- v0.1.0 (2026-11-13):
  - Initial 2D viewer: folder scan, study/series browser, slice sorting,
    background decoding, scroll/zoom/pan/invert/cine, length/angle, HU readout,
    GPU WGSL windowing + CPU fallback (`RDICOM_CPU=1`).
  - Porting map (`porting/map.toml`, `PORTING_MAP.md`) and weekly upstream
    tracker (`tools/upstream.py`, `.github/workflows/upstream.yml`).
  - Related backup from that archive: `dicom-slides-backup/` (offline backup of
    the `dicom-slides` PowerPoint add-in with a local Node HTTPS server).

- v0.2.0 (2026-11-14):
  - Non-destructive `.zip` patient archive opening & drag-and-drop.
  - Ported `IsiXGeometry` & `IsiXImaging` geometry (`ImagePlaneGeometry`,
    `ViewTransform`, `OrientationLetters`, `SliceSynchronizer`, `ReferenceLines`).
  - Ported all 31 Horos CLUTs (`src/imaging/clut.rs`) & 22 Horos 2D convolution
    filters (`src/imaging/convolution.rs`) on both GPU and CPU.
  - Ported `IsiXROI` (`src/roi/`) with Length, Angle, Oval, Rect, Closed Polygon,
    Freehand Pencil (spline-smoothed), and Point Probe + live statistics.
  - Added 4x4 visual grid layout picker (`1x1`..`4x4`), non-wheel slice/series
    navigation, Study Browser search/modality pills/38x38 mini-thumbnails.
  - Added in-place 3D MPR (`src/volume.rs`) with 3D Trackball Orbit rotation,
    Thick-Slab MIP/MinIP/Mean, Hybrid Multi-Series (AX/COR/SAG) tri-planar
    fusion, and 6-DOF 3D Rigid Registration (`RigidTransform3D`) + `Lock 3D Sync`.
